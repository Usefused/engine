# One-Click Engine Deployments

Deploy the published `ghcr.io/usefused/engine` OCI image directly to **Cloudflare Containers**, **Vercel Containers**, **Railway**, **Coolify**, or **Pxxl (`pxxl.app`)**. All templates pull the public prebuilt image so deployments never need private Go source build credentials.

## Quick Launch

| Platform | Deploy | PostgreSQL | HTTP / UI / MCP / REST | gRPC (`50051`) | Always-on Workers & Schedules |

| **Railway** | [Railway template & IaC](../deploy/railway/README.md) | Provisioned (Managed PostgreSQL 16) | Yes | Optional TCP proxy | Yes (persistent `/app/data` volume) |
| **Coolify** | [Compose stack](../deploy/coolify/README.md) | Bundled (`postgres:16-alpine`) | Yes | Optional TCP proxy | Yes (persistent Docker host) |

| **Vercel Containers** | [![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2FUsefused%2Fengine&root-directory=deploy%2Fvercel&project-name=fused-engine&env=FUSED_DATABASE_URL,FUSED_LICENSE_KEY,FUSED_ENCRYPTION_KEY&envDescription=PostgreSQL%2016%2B%20DSN%2C%20Fused%20license%20key%2C%20and%2032-byte%20base64%20encryption%20key%20(openssl%20rand%20-base64%2032)&envLink=https%3A%2F%2Fgithub.com%2FUsefused%2Fengine%2Fblob%2Fmain%2Fdocs%2Fengine-configuration.md) | External / Marketplace Postgres 16+ | Yes | No | Scales to zero when idle |

## Required Secrets (All Platforms)

1. **`FUSED_LICENSE_KEY`**: Generate a license key at [usefused.com/signup](https://usefused.com/signup) (**License key only**).
2. **`FUSED_ENCRYPTION_KEY`**: Generate once with `openssl rand -base64 32` (auto-generated by the Railway template) and keep the exact same value across restarts, upgrades, and database restores.
3. **`FUSED_DATABASE_URL`** *(auto-provisioned and wired on Railway and Coolify)*: A PostgreSQL 16+ DSN reachable from the Engine container. Fused creates and upgrades its schema automatically on startup.

## Automatic Port Binding

PaaS platforms such as Railway, Vercel, and Pxxl inject a standard `PORT` environment variable. Fused Engine resolves its HTTP listener port in the following order:

1. `--port` CLI flag
2. `FUSED_ENGINE_HTTP_PORT`
3. `PORT` (standard PaaS fallback)
4. `server.http_port` in `engine.yaml`
5. Default `8081`
